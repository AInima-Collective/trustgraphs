# Internal operations records

This directory contains implementation references, runbooks, test procedures, deployment notes,
and review records that are useful to repository contributors but are not published as product
documentation.

The public documentation lives in [`docs/`](../../docs/). Each specialized program has one public
overview there; detailed engineering records remain here so the public site does not expose
internal project history as a reader journey.

These files are working repository material. They may include historical status, environment-
specific commands, or superseded assumptions and should not be presented as current product
guarantees without review.
